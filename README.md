# Aletrai

Plataforma de jogos educacionais desenvolvida em React.

## Jogos disponíveis

- **Chão e Lava** — jogo de plataforma
- **Dungeon Quiz** — quiz com batalha de chefões
- **Jogo da Forca** — adivinhe a palavra
- **Jogo da Memória** — encontre os pares
- **Quiz** — perguntas e respostas
- **Verdadeiro ou Falso** — teste seus conhecimentos

## Tecnologias

- React 19
- React Router 7
- Tailwind CSS
- Google Generative AI

## Como rodar

```bash
npm install
npm start
```

Acesse [http://localhost:3000](http://localhost:3000) no navegador.

## Build para produção

```bash
npm run build
```
